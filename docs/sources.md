## Adapter decisions

- Start with Parks. Decode the actual array, split categories on `|`, parse 12-hour local times in `America/New_York`, validate latitude/longitude order, and keep source IDs as strings. Sanitize source HTML into display text; retain only short relevant evidence excerpts, not entire pages. Do not treat response MIME type (`application/octet-stream` here) as proof that JSON decoding will fail.
- Use Open Data only to discover seasonal leads until dataset freshness and stable row IDs are demonstrated. Inspect date bounds/metadata before proposing a live adapter.
- Libraries remain on the strategy, but no working deterministic library parser is established. Investigate documented public endpoints and source usage terms; do not bypass access blocks or substitute an aggregator. HTTP availability, parser viability, permission to reuse and listing truth are separate checks.
- Curated sources need an explicit target URL list, human approval, current occurrences and evidence. No verified winter seed inventory was produced in this research task. Do not promise that Bryant Park or unnamed community centers fill that gap.
- Respect source rate limits and HTTP cache validators. On failed/partial runs retain existing records; only a successful bounded snapshot may reconcile that same window. Save short sanitized errors in private run records.
